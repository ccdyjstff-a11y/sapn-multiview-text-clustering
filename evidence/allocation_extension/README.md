# Allocation extension: sealed evidence export

This directory contains unchanged evidence from the prospectively specified allocation extension on two previously studied corpora (20NG and AG News), five prespecified seeds each, Q=400. It is a known-benchmark extension, not a never-seen dataset test. All 50 logical final records are retained, including unfavorable contrasts. They reference 39 unique final compact prediction files because exact duplicate final fits were reused. The 30 selection records and all fold/final JSON identities and diagnostics are included.

`SOURCE_EXPORT.json` binds every copied file to its source-relative path and SHA256. `LOGICAL_PREDICTION_MAP.json` maps all 50 logical records to their 39 physical prediction files. `ARRAY_INVENTORY.json` states every exported NPZ key, dtype and shape. Original bytes and historical path strings inside records were preserved; historical paths are provenance, not portable executable paths.

Each final compact NPZ contains predicted `labels`, shared embedding `H`, and queried positive/negative endpoint pairs `P`/`N`. The field named `labels` is the model's cluster prediction, not the original corpus category vector. Query NPZ files contain the pool, queried pairs, their 400 oracle answers and non-pool indices; they do not contain a full true class vector. No raw corpus, prepared view, true category-vector file, training input/graph array or full optimizer state is distributed here. This is evidence export only; no fitting or rescoring was performed during export.

Root protocol, freeze receipt, input seal, global seal, terminal records, queries, reporting tables and full evaluation records are retained. The original manifests still name omitted artifacts, and must not be interpreted as claiming those artifacts are included. `OMITTED_FILES.json` explicitly lists them: prepared views, full states, fold prediction arrays, training/graph inputs, post-seal evaluation-pair arrays and historical logs. The existing independent post-seal rescoring report verifies 250 metric values over 50 logical records; reproducing that scoring additionally requires the separately reconstructed true categories and omitted evaluation-pair inputs.

The exact frozen wrapper and solver sources are archived, without execution, under `../../provenance/original_sources/allocation_extension/`; Python originals use `.py.txt`. Their hashes match the frozen protocol and are bound in the export ledger. These historical sources retain their original path assumptions and are not advertised as a newly verified portable training entry point. No scientific source was edited.

# Dated public input access verification

Checked on 2026-11-17. This folder records access evidence and content identities; no raw corpus archive belongs in the public release. Local downloads were used only to verify identity and, for the separately documented AG News mirror adapter, rebuild prepared inputs. No model training was performed.

The original [20 Newsgroups by-date archive](http://qwone.com/~jason/20Newsgroups/20news-bydate.tar.gz) was newly downloaded over HTTP: 14,464,277 bytes, SHA256 `8f1b2514ca22a5ade8fbb9cfa5727df95fa587f4c87b786e15c759fa66d95610`, exactly matching the frozen input. An HTTPS attempt timed out locally and an alternative Figshare request returned HTTP 403. These observations describe those attempts, not permanent unavailability. [scikit-learn's dataset source](https://raw.githubusercontent.com/scikit-learn/scikit-learn/1.7.2/sklearn/datasets/_twenty_newsgroups.py) independently records the same archive SHA256.

The [Crepe author repository](https://github.com/zhangxiangxiao/Crepe) still points to its [dataset folder](http://goo.gl/JyCnZq). The Google Drive connector listed `ag_news_csv.tar.gz` with 11,784,327 bytes and returned complete-file response metadata. Transfer of that response into this environment failed, so this audit does **not** claim a new local SHA256 verification of the author container, nor an anonymous download verification. The historical author archive's locally rechecked SHA256 is `4e2fc37d369e6e317a8b62d0d2f11d379f8c3dde60c07c35a46b069a246498ad`.

The [fastai AG News mirror](https://s3.amazonaws.com/fast-ai-nlp/ag_news_csv.tgz), identified by [fastai's own dataset definitions](https://raw.githubusercontent.com/fastai/fastai/master/fastai/data/external.py), was newly downloaded: 11,784,419 bytes, SHA256 `9a8c300eabb45750237fcc669f61cb8a3448f3ef6f6098e1ce340e444f6872be`. The compressed archive and uncompressed tar container differ from the historical author archive. All four regular member names, lengths and complete bytes are exactly equal. `AGNEWS_MIRROR_MEMBER_COMPARISON.json` records each member SHA256.

The unchanged original preparer rejects the differently serialized mirror. A separate `data_tools/prepare_agnews_mirror.py` adapter verifies the mirror container and all members, then calls the unchanged original construction function. Its actual isolated preparation matched every frozen scientific identity and full historical prepared arrays, ordered labels, source IDs, vocabulary, IDF and deduplication records. Its metadata records the actual mirror container SHA separately from the equivalent original SHA. See the adapter README and `AGNEWS_MIRROR_PREPARATION_VERIFICATION.json` supplied with that entry point.

The publishable metadata list is frozen by `METADATA_SHA256.json`. Raw `.tar.gz`/`.tgz` files, failed-transfer artifacts and local-only helper scripts must not be copied to the release. Temporary signed URLs have been omitted. These access checks establish dated observations and exact input identities, not a licence grant or long-term availability guarantee.
